# First backend implementation packet

Start with one read-only source-backed case. Choose the network, program revision, and exact event window. Preserve source responses. Write a decoder that returns a normalized event plus provenance. Compare it against an independently inspected transaction before expanding the scope.

Next, build deterministic case storage and graph construction. Keep unsupported fields and coverage gaps visible. The initial product can produce a useful timeline without a language model.

Only then attach an evidence-aware model layer using the proposed prompts and tool contracts. Preserve model/provider and prompt versions, tool inputs/outputs, authored brief, and evidence references. Evaluate on both straightforward cases and misleading shared-route cases.

Keep rehearsal and execution separate. A first policy sandbox can validate a hypothetical request against a budget and required inputs without constructing a real transaction. A signer should never be inferred from the presence of a budget in a case.

Acceptance for a public backend release: source-backed replay, documented coverage, tested decoding, measurable claim-quality checks, and truthful capability labels. Screenshots alone are not that acceptance evidence.
