# Artwork and screenshot provenance

Three original character illustrations were created for PEA with the built-in image-generation tool on 2026-10-19. The initial agent image was the identity reference for the workshop and inspection pose. The PNGs were copied into this repository without recoloring or cropping. They are original project art, not Pump.fun or REA assets.

`brand/pea-cover.png` is a code-composed banner made by `scripts/cover.mjs` from the workshop illustration and exact project text. The fourteen screenshot PNGs are native Canvas renders from the same `src/render.mjs` used in the browser. Charts and values are fixture-driven; no external agent, wallet, or RPC session is represented.

## Agent icon

Path: `brand/pea-agent.png`. Built-in generation mode, transparent background.

Use case: logo-brand. Create an original pixel-art mascot for PEA, Pump Engineer Everything, an independent AI investigation workbench for onchain launches. One charming but competent tiny engineer robot whose main body is a single round green pea. Compact 56-by-56 sprite-grid aesthetic enlarged into clean hard square pixels, rich but limited palette of fresh lime, pea green, deep forest shadow, soft cream highlights, charcoal black equipment, a tiny warm amber accent. A wide black rectangular glass visor across the upper face has one mint rectangular eye and one small amber scanning eye; no mouth. Two small black boots, two little detached mechanical gloves, a diagonal charcoal tool satchel with a tiny pea-pod-shaped clasp. One glove holds a tiny cream diagnostic card. Confident slight three-quarter standing pose, immediately legible at small size, adorable yet technical. Transparent background, full body with generous margin, centered square composition. No words, no letters, no logos, no coins, no dollar symbols, no frog, no fly, no plant stalk, no long snout, no cannon, no existing game characters, no antenna, no Claude-style body. Original retro pixel design with crisp rectangular shading, no blur, no photographic texture.
