# Release 0.1: design workbench

This release makes the proposed product concrete and reviewable. It includes original branding, fourteen workbench views, three authored cases, source code for the preview, schemas, proposed tools, agent instructions, and production design notes.

Working local features: view selection, case selection, event reveal, display calculations, PNG export, unsigned receipt export, source bundling, and screenshot reproduction. Event notional uses integer lamport arithmetic in the preview helpers.

Specified future components: Solana ingestion, program-version-aware decoding, persistent evidence storage, model-generated briefs, claim evaluation, and a policy sandbox. The tool catalog is a proposed interface rather than a registered MCP server. Signing and trade broadcast are not connected.

Every case uses synthetic data. The fixture events are not a live Pump.fun feed. Agent briefs and counterexamples are authored examples. The curve is a generic constant-product teaching model; it is not a production quote.

This separation is intentional: the current deliverable is a detailed design repository with a polished, navigable visual workbench. The implementation roadmap defines the next milestones without claiming that they have already shipped.
