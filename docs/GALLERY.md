# Workbench gallery

Fourteen 1680 × 1050 native Canvas captures of the design workbench. Every case is synthetic. Most captures use First Light; Challenge Room uses Common Route, and Session Replay uses Missing Pages at a 68% event cursor. These are rendered design screens, not evidence of a live agent or blockchain session.
