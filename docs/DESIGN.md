# Visual design

PEA's interface is an engineering notebook with an agent inside it. Cream headers, charcoal surfaces, lime highlights, and a small amber scanner accent distinguish it from a conventional market dashboard.

The original mascot is a round pea engineer with a broad black visor, asymmetric mint/amber eyes, a diagonal satchel, gloves, and boots. The workshop and inspection pose use the same identity reference. The illustrations are pixel artwork; the interface text and charts are drawn separately for clarity.

The top navigation presents fourteen views in two rows. A shared case strip carries fixture event count, sample flow, buyer count, and coverage. Scene layouts change to fit the question: table, timeline, graph, decoder view, challenge board, policy panel, or receipt.

Observed claims use lime, interpretations use amber, and unresolved statements use muted text. Text labels accompany color. The workbench always identifies its synthetic data and design-release status.

The native captures are 1680 × 1050. The responsive browser Canvas uses the same drawing code. Narrow devices scroll horizontally to preserve the numerical labels. The toolbar uses native labeled controls; a full live text alternative for every chart remains future accessibility work.
