# Research references

Reviewed for this design on 2026-10-19:

- [REA official repository](https://github.com/morluto/rea) and [official site](https://rea.tools/): primary references for an agent-assisted software-inspection workflow. PEA is independent, and no REA code or artwork is bundled.
- [User-supplied X post](https://x.com/0xCodila/status/2109623431763292649): direct automated access returned HTTP 403 during preparation. The design was grounded in REA's official sources instead of attributing unverified claims to that post.
- [Pump.fun public documentation and IDLs](https://github.com/pump-fun/pump-public-docs): primary integration reference. Production work must pin the relevant schema and behavior revision.
- [Pump program documentation](https://github.com/pump-fun/pump-public-docs/blob/main/docs/PUMP_PROGRAM_README.md): additional protocol context. The simplified teaching curve is an independent illustration, not a reproduction of its execution behavior.
- [Solana getTransaction](https://solana.com/docs/rpc/http/gettransaction): primary reference for a proposed source adapter.
- [GitHub file upload instructions](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository): folder-upload guidance.

These references explain the topic and intended integration boundary. They do not establish a partnership, affiliation, audit, tested backend, or live deployment.
