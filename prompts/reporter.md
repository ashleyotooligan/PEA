# Case brief task

Write a concise public brief with the following fields: question, source boundary, observations, interpretation, alternatives, unknowns, and next evidence request.

Attach each substantive factual statement to event IDs. Include the case's coverage note. Describe derived metrics accurately and preserve their units. Avoid confidence percentages unless an evaluated calibration method is explicitly supplied.

End with the receipt identifier or artifact reference when available. An unsigned local digest should be described as a payload-integrity record, not a signed or onchain proof.
