# Counterevidence task

Review a proposed claim using only the supplied case and authorized source tools. Identify assumptions that exceed the evidence. Look for plausible alternate routes, shared services, missing predecessors, incomplete pages, schema mismatch, or fee/routing effects when relevant.

Return supporting evidence, counterevidence, open questions, and a revised claim status. A useful response may leave a claim unknown. Do not assert that an alternative occurred merely because it is plausible.
