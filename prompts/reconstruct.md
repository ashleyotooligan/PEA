# Launch reconstruction task

Given a case window and retained source references, build an event timeline. Preserve instruction order where available, source gaps, program/schema revisions, and quote units. Normalize only supported records.

Report which events are directly observed, which values are derived, and which conclusions require additional history. Explain the first meaningful sequence in ordinary language and attach its evidence IDs.

If two events share a slot and finer ordering is unavailable, say that the sub-slot order is unresolved. Do not invent a precise chronology from display order.
